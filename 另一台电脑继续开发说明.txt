【一、新电脑必装（两样）】

1. Godot 4.7.1 Mono 版（必须带 Mono/.NET 后缀！普通版跑不了 C#）
   - 下载：https://github.com/godotengine/godot-builds/releases（找 4.7.1-stable Mono）
   - 本项目在老家电脑用的是 4.7.1.stable.mono，新电脑装同版本最稳

2. .NET SDK 8.0（LTS 版即可，8.0.4xx 以上）
   - 下载：https://dotnet.microsoft.com/download/dotnet/8.0
   - 装完命令行输入 dotnet --version 能出版本号就是好了

【二、打开项目】

1. 解压本压缩包到任意位置（路径别带特殊符号）
2. 双击项目文件夹里的 project.godot，用 Godot Mono 版打开
   （或先开 Godot → 导入 → 选 project.godot）
3. 第一次打开会自动重建 .godot 缓存文件夹，属正常现象
4. 第一次编译 C# 需要联网（自动从 NuGet 下载 Godot.NET.Sdk 4.7.1）
   打开项目后在编辑器右上角点「构建」或按 Ctrl+Shift+B

【三、本项目关键信息】

- 程序集名：FangGuogeGame（.NET 8.0）
- 主场景：res://scenes/main_menu/main_menu.tscn
- 全局单例：GameManager（res://scripts/autoload/GameManager.cs）
- data/dialogues、data/choices 是空目录，运行时读写对话数据用，
  别删，删了对话系统可能报错
- 渲染用 GL Compatibility（兼容低配机）

【四、常见问题】

Q: 打开时提示引擎版本不符？
A: 项目特性标记为 4.7，用 4.7.x Mono 打开；用 4.6 或 4.8 可能弹转换提示。

Q: C# 脚本报错/不智能提示？
A: 确认装了 .NET SDK 8，且在编辑器里「项目 → 工具 → C#」创建过解决方案，
   或直接点构建一次。

Q: 缺字体/图片？
A: 不可能缺，全部资源都在 res:// 项目内，无外部引用（已扫描核实）。
