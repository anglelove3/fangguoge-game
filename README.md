## 📖 这是个什么游戏

改编自个人短篇小说《放过哥》的 16 章互动叙事：一个研二男生从"放过自己"到"开始懂了"的感情与成长故事。
**双隐藏属性**（好感度 / 勇气值）随剧情选择累加，复玩内容不计分；**章节末按数值档位判定结局倾向**（共 4 种结局）。
所有剧情、聊天、数值、闲笔全部 **JSON 数据驱动**，每轮发布前跑全流程自动化回归。

### 已实装（序章 + 第一~十五章）

- **第十五章《那束光》**：网咖包夜——前台她抢着请客、包间两台并排的机器、开黑三拍小游戏；
  深夜她靠在肩上睡着，你可以盖外套 / 把她的屏幕调暗再挡住那束光 / 叫醒她。（场景为程序绘制）
- **第十四章《爱就梭哈》**：三月七日，她第一次来他的学校——校门 / 校园三处闲笔（顺序随意）/ 小馆心声 / 实验楼下的「你的心跳得好快」三选一（承认 · 嘴硬 · 把耳机分她一半），收在"不算里程"的梭哈里

- **微信模拟系统**：可交互手机桌面（12 个 App）+ 四标签微信主界面 + 17 人角色卡 + 群聊/置顶/朋友圈点赞动效
- **三线分层聊天**：玩家的选择决定她"知不知道你要来"，全程两种消息心情（互斥门控钥匙实现）
- **RideTrack 公路滚行组件**：389 公里南下骑行——背景漂移、路牌掠过、五档天光、雨幕粒子、脚本化电量 HUD
- **跨章剧情联动**：第十章的充电选择，直接决定第十一章你是"骑到街口"还是"推 5 公里进城"
- **自动化回归**：全流程模拟点击回归（逐轮 20~75 项断言），抓掉过数十个真 bug

## 🛠 技术栈

Godot 4.7.2（Mono/.NET 8）· C# 3.07 万行（77 个文件）· GDScript 测试驱动 · 全 JSON 数据驱动 · GitHub Actions 无（纯本地回归）

## 📂 仓库导览

- `scripts/` — 全部 C# 代码（`chapters/` 章节、`ui/` 组件、`autoload/` 单例）
- `data/` — 剧情/聊天/角色卡/数值等 JSON（93 份）
- `scenes/` — 场景文件（各章 + UI）
- `CHANGELOG.md` — 每轮发布说明（日期 + 改动明细 + 回归数字）
- Releases — 试玩包下载（v1.5.0，固定直链 `releases/latest/download/fangguoge-demo-win64.zip`）
