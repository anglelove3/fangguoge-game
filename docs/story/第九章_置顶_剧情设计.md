> 依据《游戏开发设计方案》第 9 章规划 + 本轮四项拍板：
> **基调**＝暧昧期 + 成长线；**形态**＝手机与现实交替 + 新机制「内心解读」；
> **礼花筒**＝本章拉掉；**范围**＝本章 + 顺手清 r17 四条遗留观察。

## 一、这一章在讲什么

第八章是"承认"——他终于说出"还想再见"。第九章是**学习**：学会了喜欢一个人之后，日子怎么过。

原案的三个词，本章全部做实：

- **置顶**——他把她置顶了，还要骗自己"只是方便找"。但置顶不是功能，是他每天打开手机的理由。
- **没事算不算没事**——她深夜发来两个字"没事"。这是本章的戏眼：同一句话，读法不同，回法不同，走出的路也不同。**新机制「内心解读」**就长在这里。
- **成长线**——上一章她说"都行。那你定"，他慌了一晚。这一章他要学着把"我定了"三个字说出口；学着不盯着手机等回复，先把自己的日子过好；学着把兜里那枚礼花筒，等到该拉的时刻。

情感落点（写在尾声）：
> （以前我以为"等"是喜欢一个人的方式。现在才懂，把自己过好、然后稳稳地走向她，才是。）

## 三、新机制：内心解读（本章招牌）

她说一句模糊的话 → 屏幕上方浮出**她的原话气泡** → 下方推出三张"解读纸片"（三种内心读法）→ 玩家选一种 → 主角按那种读法回复 → 她的回法随读法分层。

- 技术上：新组件 `ReadCard`（她的原话 + 三张纸片，样式复用心声纸片那套质感），走**主线选择**（记数值 + 进选择回顾），不是心声微选择——这次的选择真的改变他说出口的话。
- 原型是第八章第 1 幕"三条草稿"的镜像：草稿是**写了又删**（不敢发），解读是**读了才回**（学理解）。两个演出首尾呼应。
- 本章用 1 次（"没事"那场戏）。做一次做透，不贪多。

## 五、分幕流程与互动清单

### 第 1 幕 · 周一夜，宿舍（置顶仪式）

- **开场对白**（7 行）：第二次见面回来第三天，聊天列表他翻上翻下。金艮在群里问"进展"，他回"正常交流"（被拆穿）。
- **主线演出：亲手置顶**——长按她的会话 → 弹微信式菜单 → 点"置顶聊天" → 会话带着小动效跳到列表顶端。**列表顶部显示第八章玩家起的备注名**。
- **心声微选择 `pin`**（无数值，记 `ch09_heart_pin`）：置顶之后，他在心里怎么跟自己解释——
  - ① 「只是方便找。」（嘴硬）
  - ② 「置顶的人，是每天都要说话的人。」（承认一半）
  - ③ 「什么时候置顶也成习惯了，就好了。」（看得最远）
- **闲笔热点**（`data/flavor/ch09_dorm1.json`，2 处）：书桌上摊开又合上的论文（导师第 19 遍还没改完）、床头那本《开始懂了》磁带盒（呼应序章）。
- **动态事件**：`ch09_jie_evening`（她：今天风好大，你的围巾记得带上。——呼应第二章"我这边风好大"，风向她那边吹回给他）

### 第 2 幕 · 周三下午，实验室（成长线：先把自己的日子过好）

- **主题对白**（9 行）：她的回复有时快有时慢。旧的他会对着"对方正在输入…"发呆半天；这一章他**把手机扣在桌上**，去把样品跑完、帮小米师妹调了一下午参数、跟三金师兄抬了一箱试剂。
- **演出：手机震动三次他都没看**——三次 toast 依次弹出（她的消息/li-lab 群/她第二条），他全部"稍后回"。等他终于拿起手机，她已经连发了三条，最后一条是「看来你今天很忙嘛」（带一点笑的醋）。
- **主线选择 `busy`（三选一，一涨一跌）**：怎么回——

  | 选项 | 文案 | 数值 |
  |---|---|---|
  | A | 「在忙。晚上聊。」（诚实，但硬） | 勇气 +3 / 好感 −2 |
  | B | 把一下午的事讲给她听：样品、试剂箱、师妹的参数（分享生活） | 好感 +5 / 勇气 −1 |
  | C | 「没忙。」（其实跑了一下午，就想快点回她） | 好感 +3 / 勇气 +2 |

- **动态事件**：`ch09_li_group`（li-lab：三金师兄凌晨改样品被抓包，群嘲一波——实验室压力闲笔延续）

### 第 3 幕 · 周四深夜，宿舍（戏眼：没事算不算没事）

- **铺垫**（6 行）：她白天随口提过"最近在忙一个事"。深夜十一点半，她发来一句「在吗」，他秒回，她隔了很久才说：「没事。」
- **★ 新机制「内心解读」全场戏**：她的原话气泡浮出——「没事。」三张解读纸片：
  - ① **字面读**：真的没事，就是想找个人说句话 → 回「我在。你随便说，我听着。」→ 她真的开始说（说些零碎小事）→ 好感 +4 / 勇气 −1
  - ② **读出有事**：说"没事"的人都有事 → 回「现在没事，可以有事。」→ 她沉默十几秒，说了真事（论文被导师否了第三版 / 家里的事，二选一预设）→ 好感 +2 / 勇气 +4
  - ③ **读出想见他**：深夜的"没事"是想见又不好意思说 → 回「周末见一面？有些话当面说。」→ 她发来一个"嗯。"→ **直接接第四幕的约** → 好感 +1 / 勇气 +5
  - 三条都能走到第四幕，但第四幕开场对白和她的状态不同（①她心情已被接住、②她带着心事赴约、③她其实等这句好几天）。
- **心声微选择 `late`**（无数值，记 `ch09_heart_late`）：她下线后，他看着"置顶"那一栏想什么（三个短句，最后一个呼应"没事算不算没事"——「原来'没事'的意思，要看是谁说的。」）

### 第 4 幕 · 周六黄昏，河堤（成长线兑现 + 礼花筒拉掉）

- **开场**：这次是**他定的**。主线选择 `plan`（三选一，一涨一跌）——

  | 选项 | 文案 | 数值 |
  |---|---|---|
  | A | 「沿河堤走，走到桥头再折回来。风大，我把围巾带来了。」（提前查了天气和路线） | 好感 +4 / 勇气 +2 |
  | B | 「去罗曼蒂克，把上次没打完的局打完。」（熟的地方不紧张） | 勇气 +1 / 好感 +2 |
  | C | 「我定了地方，到了你就知道。」（真的藏了一个安排） | 勇气 +5 / 好感 −2 |

  （A 的"围巾"直接兑现第 1 幕她那条动态事件；**C 的隐藏安排＝两个物件都有（拍板结果）**：他提前踩过点、知道傍晚风起时桥洞的风铃会响，兜里还揣着排长队买的糖炒栗子——风铃响时他把栗子分她一袋，"栗子是顺路的，风铃才是踩过点的"。）
- **河堤走段**：`river_dusk_v1` 背景 + 三个互动热点（护栏/水面/桥影），闲笔对白穿插她的状态（按第三幕读法分层）。
- **★ 礼花筒拉掉（本章情感最高点）**：走到桥头折返点，天快黑透。他停下来，从口袋里摸出那枚礼花筒——捏了两下（第八章同款动作）——这次拉响了。`sfx_party_popper`，彩带迸进河风里飘散。
  > 江洁（`jie_surprise`）：「这就是上次你兜里的东西？」
  > 我：「嗯。下次的东西。」
  > 我：「下次，就是现在。」
- 彩带落定后她的一段安静对白（不写"在一起"，写到"两个人都懂了"为止——把"确定关系"留给第十二章《爱就梭哈》）。
- **心声微选择 `popper`**（无数值，记 `ch09_heart_popper`）：彩带落进风里那一刻他心里的一句话。

### 第 5 幕 · 周六夜，宿舍（收束）

- 回宿舍，手机列表顶端还是她。他给今晚发了最后一条消息，她回了个笑脸。
- 收束对白（5 行）+ 尾声落点段（见"一、这一章在讲什么"）。
- **演出细节**：他把聊天列表上滑到底又滑回顶——置顶的她一直在最上面，怎么滑都不会走。（一句旁白：「置顶的意思就是——无论滑多远，一抬头就能看见。」）
- 淡出 → `demo_end`（清单更新为"序章 + 第一～九章"）。

## 六、数值纪律

- 本章真选择 2 处（`busy` / `plan`）+ 内心解读 1 处（`read`，也走主线选择）＝**共 3 处**，每条严格"一涨一跌"；心声微选择 4 处（`pin` / `late` / `popper`，实际 3 处）**一律不加数值**。
- 本章浮动上限：好感 +9 / 勇气 +11；下限：好感 −3 / 勇气 −3。
- 结局门槛核对（结局 A 需 好感≥70 且 勇气≥70）：第八章末最高约 好感 81 / 勇气 73；第九章走完最高约 好感 90 / 勇气 84——**A 结局在本章末基本落袋**（第十章还会再考勇气），符合"暧昧收束、勇气线留给公路章"的节奏。
