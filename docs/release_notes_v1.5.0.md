## 试玩版 v1.5.0 · 第十四章《爱就梭哈》

从 v1.4.0 到这一版，多了**第十四章**，另外修掉两处试玩反馈里的真问题。

### 新增：第十四章《爱就梭哈》

三月七日周六，她第一次来他的学校——这一次是**江洁**把 389 公里走完的。

- **校门**：她坐高铁转大巴到，说了别接；他"下楼买酱油"买了一个小时
- **校园**：三处闲笔（梧桐路灯 / 树下的橘子与"论文第几遍" / 路尽头亮着灯的图书馆），顺序随意，点完才放行
- **小馆**：「你算得太细了」「那你算过我们要怎么办吗」
- **实验楼下**：「你的心跳得好快」——**承认 / 嘴硬 / 不回答把耳机分她一半**（三个分支各自的收尾不一样）
- 收在"不算里程"的那句梭哈里，钩子指向下一章《那束光》

### 修复

- **章末「—— 第X章 完 ——」的章号对不上**：第六、七、八章写的是旧的第五、六、七章（插入《晚安》之后整体后移，这三张卡没跟着改）。已改正，并补齐第四、九~十四章的章末卡，全书 14 章统一。
- **切章卡顿**：以前换章时"黑一下 → 僵住 → 弹出来"，实测最重的一章单帧卡了 1.3 秒。现在改成后台线程预载下一章（场景 + 背景贴图 + BGM/环境音），并让黑屏多留 0.28 秒把首帧盖住；返回主菜单也改成了同样的淡出。
- **结局页的章号**：选择回顾里从《手滑》起全部少算一章（32 处），已逐条对齐。
