## 四、系统层

| 系统 | 说明 |
|---|---|
| 存档 | 单档 + 旧档自动备份（BeginNewGame 前）、跨章数值（好感/勇气/心声/选择记录） |
| 手机 | 锁屏（**壁纸三态**：分手前昼夜 / 分手后雨窗 / 江洁期向日葵）+ 桌面（11 个拟真 App 图标）+ 微信全套 + **QQ 空间** + 相机/音乐/邮箱等 |
| 微信 | 会话/通讯录/朋友圈/新的朋友（真实加好友）/群聊/备注/置顶/未读角标 |
| 背包 | 物品详情 + 已用物品文案变化 + **物品记忆**（每件东西一段当时的回忆） |
| 章节选择 | 主菜单「继续游戏」→ 已玩章节任选；结局页也可挑章重玩 |
| 结局页 | 选择回顾（demo_review）+ **「有些选择，没有选项」**（钥匙/拔刀数/QQ照片/前女友微信/河边不选） |
| 无障碍 | 文字大小调节（0.85~1.35）、Ctrl 快进 ×8 |
| 音频 | BGM 分章（9 首）+ 环境音分章 + 音效（点击/悬停/打字/落盘/破碎/心跳） |
