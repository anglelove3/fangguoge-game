> 触发：第四轮试玩反馈「有些章节些许卡」，当时只加了 F3 帧耗时叠层，没跑数据。
> 本报告是第一次全章量化测量。

## 方法

- 驱动：`test/perf_check.gd`（不进仓库）
- 环境：窗口模式真实渲染（RTX 4070 Laptop / NVIDIA 581.57 / OpenGL Compatibility）
- 每章：加载 → 预热 3 秒（跳过贴图解码与字体首次排版）→ 采样 5 秒
- 指标：`Performance.TIME_PROCESS`（CPU 帧时间 ms）、`TIME_FPS`、`RENDER_TOTAL_DRAW_CALLS_IN_FRAME`
- 未加 `--fixed-fps`（否则帧时间恒定，测不出东西）

## 结论

### 1. 没有掉帧，整体是流畅的

全部 17 个场景：**平均 FPS 120（vsync 上限），最差 FPS 119~117**。也就是说没有任何一章真正掉帧——玩家感受到的"些许卡"不是帧率问题，而是**单帧尖峰**（p95 20~35ms，在 120Hz 预算 8.3ms 下相当于卡了 2~4 倍一帧，被 vsync 吸收，表现为"隔一会儿顿一下"）。

### 2. 尖峰集中在三章

- **Ch13（p95 34.87ms）**：送别长镜头 + 尾声三变体，疑似同时挂着多组逐帧特效（雨窗/火星/心刃一类）
- **Ch12（p95 25.09ms）**：骑行 `RideTrack` 每帧大量 `DrawLine`/多边形（第四轮已点名）
- **Ch06（p95 24.93ms）**：碎裂演出 `ShatterPhoto` + 凌晨压暗层

### 3. 绘制调用≠性能瓶颈

Ch16 峰值绘制 **142**（全库最多），但平均 8.89ms / p95 10.04ms——**最快的章之一**。说明瓶颈不在"画多少"，在"每帧重算多少几何"。

### 4. 静态待机零错误

17 章各跑 8 秒，日志里 **0 个 ERROR / 0 个 WARNING**（仅退出时 ObjectDB 泄漏提示）。

## 如果要继续压（按性价比排序）

1. **Ch13 定位尖峰**：在 `test/perf_check.gd` 基础上加"逐帧记录尖峰帧号"，对照演出时间轴找触发点；
2. **`RideTrack` 调细分**：远景线条分段数减半、远景贴图化（第四轮建议）；
3. **台球静止不重绘**：`BilliardGame` 现在每帧 `board.QueueRedraw()`，可改为"球在动才重绘"；
4. **逐帧特效加 `Visible` 门控**：`RainWindow` / `BalconyNight` / `WindowFog` / `HeartBlades` 隐藏时仍每帧重绘（当前没门控）；
5. **低配开关**：设置页加"关闭逐帧特效"。

> 当前优先级建议：**先不优化**。120 FPS 下玩家体感已经够顺，等 bug / 美术 / 音乐那几摊收完，如果还有人反馈卡再按上表动手。
