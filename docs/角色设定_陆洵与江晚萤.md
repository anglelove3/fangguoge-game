# 陆洵与江晚萤（当前设定）

这是原创化角色，不是现实人物的肖像。学校、城市、账号、信件原文和精确日期继续虚构。

## 陆洵

研三，面临毕业，汪老师的学生。和金艮、诚哥是同一届的好朋友。叙述用「我」，别人可以叫他陆洵。外号仍是序章选定的耳机哥、都行哥、放过哥。

他安静，受伤后会退回壳里反复想；压力大时抽烟、熬夜。自我认知和沟通都偏慢，经常等事情积起来才说。这些是他要成长的部分，但不能用来解释前任的隐瞒。

前任在恋爱期间另有新人，还把问题说成他不够体贴、不够浪漫、没有安全感。分手不到一个月，又有一封推卸责任的信。游戏只呈现改写后的碎片。

他先把相框扣下，再收进抽屉。想过扔掉，但学位证等重要物品还在，最后请朋友一起装箱寄回，并注销旧的短视频账号。

固定外观：不戴眼镜。用一根细深棕绳把很小的银色卡祖笛挂在颈间，落在上胸位置。卡祖笛要保留吹口和笛膜鼓包的真实轮廓，不能画成领夹、项链吊坠或狗牌。

秋冬穿搭：户外戴低矮软塌的米白韩系针织帽，穿深灰蓝短工装夹克、燕麦灰圆领针织衫、水洗黑直筒牛仔裤和旧白帆布鞋。进入室内后摘下针织帽和夹克，放在椅背；不是常年戴帽的人。基准图为 `美术打磨/角色/陆洵/穿搭_秋冬_v1.jpg`。

发型允许在同一长度内轻微变化：日常是自然短碎发；戴帽时只露少量额前和鬓角碎发；摘帽后顶部稍压平并随手抓松几缕；正式场合只向侧面轻整理。不做明显中分、烫卷、长发或油亮定型。基准图为 `美术打磨/角色/陆洵/发型变化_v1.jpg`。

秋冬正式约会：用暖色层搭与江晚萤的深莓红短外套形成配色对话。驼色中长羊毛外套敞穿，内搭燕麦麻花圆领针织和浅蓝牛津衬衫，配深巧克力色直筒灯芯绒裤与深棕低跟切尔西靴。不戴帽，短发轻微侧梳；卡祖笛和木珠串保留。外套轮廓要清楚，不能再画成全身藏青或只有一层毛衣。基准图为 `美术打磨/角色/陆洵/穿搭_约会_v3.jpg`。

遇见江晚萤之后，戒烟是他自己的决定。珠串是她在普通日子里送的，他自然戴着，不拿来当证明。

## 江晚萤

研二。和小米师妹是闺蜜，由小米带进局里；不是汪老师的学生。即便没有陆洵，她的主线也是学业，以及之后可能去另一座城市深造或工作。

固定外观：不戴眼镜，长黑发自然披下，额前略有弧度；不扎马尾、丸子头或半扎发。日常佩戴细银项链、小吊坠和一对短银耳坠；约会银饰可以换成更醒目的同系列月光石款。

秋冬穿搭：烟灰棕中短呢外套、奶白宽松卫衣、浅蓝宽腿牛仔裤、黑色短靴和棕红帆布单肩包。窄版烟棕旧围巾只松绕一圈，保留轻微起球，不能遮住下巴或脸；进入室内后与外套一同搭在椅背。基准图为 `美术打磨/角色/江晚萤/穿搭_秋冬_v1.jpg`。

发型变化只发生在披发内部：可在偏中分与轻微四六分之间调整；一侧可自然别到耳后；围巾只轻压发尾；室内发尾可以稍蓬；雨天只让最下层发梢微湿成束。长度、发量和黑色保持不变，不增加任何扎发或发卡。基准图为 `美术打磨/角色/江晚萤/发型变化_v1.jpg`。

秋冬正式约会：保留深莓红上大腿短款牛角扣呢外套，内搭暖象牙粗针开衫和奶油高领打底。下装为可可棕高腰 A 字羊毛中长裙，裙摆到小腿中下部；腿部穿自然哑光肤色加绒连裤袜，再叠可可棕短堆堆袜。鞋用焦糖驼色麂皮包后跟厚底鞋，必须画出圆头、厚底、侧边金属扣、鞋面侧向镂空和完整包住的后跟，不能画成露后跟穆勒、双搭扣 Boston、凉拖或居家拖鞋。搭小号深棕红硬挺肩包。长发轻微四六分，发尾做柔和大弧度吹整，单侧别耳。基准图为 `美术打磨/角色/江晚萤/穿搭_约会_v4.jpg`，鞋型参考为 `美术打磨/角色/江晚萤/鞋_约会_包后跟厚底_v1.jpg`。

约会装饰：双层月光石银项链；左手月光石手链加一条细银链叠戴；肩包短银链挂一颗小月光石和一枚小星星；短银耳坠加一侧银色耳骨夹；右手食指一枚细银戒；外套领口一枚小银月亮胸针。项链、手链和包链要在中景可辨认，耳骨夹、戒指和胸针保持小；左手腕手链仍由陆洵所送。

这次约会她准备约两小时：洗发吹整、精细底妆、玫瑰棕眼妆、细长眼线、分簇睫毛、蜜桃玫瑰腮红、莓果水光唇、试衣熨衣、换包和检查随身物品。效果要非常漂亮且明显比日常精致，但必须保留本人脸型和皮肤纹理，不能画成网红脸或舞台浓妆。

两个人都喜欢吃粉。第十三章见面后，她带陆洵去老街的「盛鲜生杀猪粉」，两人不用商量就点了两碗杀猪粉。

她用四类小事建立信任：兑现很小的承诺，记得细节，他沉默时不逼问也不消失，愿意为见面花时间和路程。这些分散在不同章节，不设一个拯救时刻。

她需要陆洵逐步学会：及时说明自己的状态，主动安排见面和未来，把在乎说出来，并尊重她的学业选择。

## 结局

所有路径都通向同一个好结局。选择只改变他何时说出口、如何处理旧物，以及结局里出现哪些细节。

过程是：短暂异地并共同做计划，他靠持续准备获得靠近她的工作，两人完成各自的阶段目标后在约定城市会合。最后闪回数年后有阳台的明亮小家、共享书桌、两把吉他、珠串，以及一只原创布偶猫。谁也不用放弃前途来交换团聚。
