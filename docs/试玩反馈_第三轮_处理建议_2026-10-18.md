### 🔴 根因 A：美术坐标系统的基准尺寸是错的（一次修掉 #1 #5 #7 #9，并改善 #3）

`scripts/ui/ArtAnchor.cs` 写死了：

```csharp

public const float ArtH = 1024f;
```

实测素材：**20 张背景是 1792×1024，但有 11 张是 1536×1024**——


1536 宽的图在 16:9 视口里按 cover 缩放后，画面上每个物体相对"ArtAnchor 以为的位置"，
横向偏大约 **1.167 倍**、纵向整体下移约 **85px**（美术坐标系下）。结果就是：
**所有写死的热点、贴片，在 11 张 1536 图上都会"飘"到旁边的东西上。**

## 一·五、🔴 根因 F：台球"卡死"= 物理死锁（#11，已用数值复现）

**不是状态机问题，是球永远停不下来。**

`scripts/ui/billiard/BilliardGame.cs:472`：

```csharp
if (b.Vel.LengthSquared() > 1f)      // ← 速度 > 1 px/s 才施加摩擦
{
    b.Vel *= Mathf.Exp(-Friction * dt);
    if (b.Vel.Length() < StopV)       // StopV = 7
        b.Vel = Vector2.Zero;
}
```

而 `AllStopped()`（第 566 行）判断的是 **`b.Vel != Vector2.Zero`（精确等于零）**。
于是：**任何速度落进 (0, 1] px/s 区间的球，既不再减速、也永远不清零**，
它会以恒定 1 px/s 以内一直滑下去 → `AllStopped()` 永远为 false → 卡在 `GState.Sim`，
而 `OnPress` 只在 `Placing / Aim` 两态受理点击（第 1194 行）→ 玩家点什么都没反应，只能退出。

**这个速度区间非常容易命中**：球球碰撞的冲量是 `velN*(1+0.97)/2 = 0.985·velN`，
击球方会留下 **1.5% 的残余速度**——只要撞击前速度低于约 **67 px/s**，残余就 ≤1 px/s。
换句话说：**轻推、贴库、江洁打得软一点，都会把台面锁死**。库边反弹（`×0.72`）也可能落进同一区间。

复刻同一套常数跑出来的结果：

| 撞击前速度 | 残余速度 | 60 秒后 | 是否停下 |
|---|---|---|---|
| 60 px/s | 0.90 px/s | 0.900（漂了 54 px） | ❌ 永不停 |
| 50 px/s | 0.75 px/s | 0.750（漂了 45 px） | ❌ 永不停 |
| 40 px/s | 0.60 px/s | 0.600（漂了 36 px） | ❌ 永不停 |
| 300 px/s（正常） | — | 3.58 s 後归零 | ✅ 正常 |

**改法（约 10 行，建议今天就热修）**：
1. 去掉 `> 1f` 守卫——摩擦**每帧都加**，速度低于 `StopV` 直接归零；
2. `AllStopped()` 改成 `LengthSquared() < 1e-4f`（别指望浮点精确等于零）；
3. 加一道看门狗：`Sim` 态持续超过 8 秒 → 强制把所有球速度清零并 `ResolveShot()`，
   以后无论物理出什么幺蛾子都不会再锁死玩家；
4. 顺手在锁死时 `GD.Print` 一次球速表，便于以后定位。

> 这条修完，"江洁打完一杆就卡住"应该直接消失；她下一杆会不会打、打得好不好，是批次 3 的 AI 话题。

## 三、需要你拍板的 6 个选择

**选项 A · 手机交互模型**（#1 #5 #7 #9 的核心）
- **A1（推荐）**：手机只在"画面里真的画了手机"的场景出现热点；其余所有要推剧情的地方，改成**背包点手机**就推进（背包已经有"打开手机"入口，改造成本低，也最符合直觉）。
- A2：画面热点 + 背包双入口并存（保留现状，但必须把热点全部归位）。
- A3：彻底取消画面手机热点，一律从背包开。

**选项 B · 夜市环境音**（#6b）
- **B1（推荐）**：新做一条 40s 夜市人声底噪（一次性，可复用到其他人群场景）。
- B2：复用现有 `sfx_wedding_crowd_loop` 降调降音量当底噪（零成本，但"婚宴感"可能串味）。

**选项 C · 贴片返修口径**（#1 #3 #6）
- **C1（推荐）**：关键贴片（手机、酒瓶）用 AI 重绘到统一水彩风，边缘羽化后入库（约 2 次生图，每次 5–10 积分）。
- C2：纯本地修边+调色（零积分），只能"遮丑"，比例和画风仍是旧的。

**选项 D · 第三章三张卡片**（#2）
- **D1（推荐）**：缩小 + 挪到留白处 + 换成"压在桌面上的水彩照片"质感（去掉奶油 UI 底）。
- D2：只缩小、只挪位置，样式不动（最保守）。
- D3：保留奶油卡片，但加"贴近桌面"的透视与投影。

**选项 E · 台球江洁**（#11）
- **E1（推荐）**：先修卡死（必修），再把"按你的杆法/力度/是否犯规"扩成 3～4 套反应台词。
- E2：只修卡死，台词沿用现有分档。

**选项 F · 通关解锁**
